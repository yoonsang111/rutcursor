# 보안 그룹 수정 - 상세 가이드

## ✅ 왜 보안 그룹 수정이 좋은가요?

**장점:**
- ✅ 표준적인 방법
- ✅ SSH 접속 가능 (일반적인 방법)
- ✅ 장기적으로 유지보수 용이
- ✅ 다양한 도구 사용 가능

**Session Manager:**
- 편리하지만 AWS에 종속적
- 일부 도구와 호환성 문제 가능

---

## 🔧 보안 그룹 수정 단계

### 1단계: 보안 그룹 화면 접근

**방법 A: 인스턴스에서 접근**
1. EC2 콘솔 → 인스턴스
2. `tour_stream` 인스턴스 선택
3. 하단 "보안" 탭 클릭
4. 보안 그룹 이름 클릭 (예: `sg-021c2479c7157707c`)

**방법 B: 직접 접근**
1. EC2 콘솔 → 보안 그룹
2. 보안 그룹 목록에서 찾기
3. 이름: `default` 또는 ID: `sg-021c2479c7157707c`

---

### 2단계: 인바운드 규칙 확인

**보안 그룹 화면에서:**
1. **"인바운드 규칙" 탭 클릭**
2. **현재 규칙 목록 확인**
   - SSH 규칙이 있는지 확인
   - 없으면 추가 필요

---

### 3단계: 규칙 추가/편집

**버튼 위치 찾기:**

**옵션 1: 상단 버튼**
- 화면 상단 오른쪽
- "인바운드 규칙 편집" 또는 "편집" 버튼
- 주황색 또는 파란색

**옵션 2: 테이블 상단**
- 인바운드 규칙 테이블 위
- "규칙 추가" 또는 "편집" 버튼

**옵션 3: 각 규칙 옆**
- 규칙 목록에서 각 행 옆
- "편집" 또는 "삭제" 아이콘

---

### 4단계: SSH 규칙 추가

**규칙 편집 화면에서:**

1. **"규칙 추가" 클릭** (또는 "추가" 버튼)

2. **다음 정보 입력:**
   ```
   유형: SSH
   프로토콜: TCP (자동 선택됨)
   포트 범위: 22 (자동 입력됨)
   소스: 
     - 옵션 1: "내 IP" 선택 (권장)
     - 옵션 2: "사용자 지정" → "0.0.0.0/0" 입력
   설명: SSH 접속용 (선택사항)
   ```

3. **"규칙 저장" 클릭** (또는 "저장" 버튼)

---

## 📋 필요한 포트들

### 지금 추가할 포트

**SSH (22번 포트):**
- 서버 접속용
- 소스: "내 IP" (권장)

### 나중에 추가할 포트

**HTTP (80번 포트):**
- Let's Encrypt 인증서 발급용
- 소스: `0.0.0.0/0` (모든 IP)

**HTTPS (443번 포트):**
- 웹사이트 접속용
- 소스: `0.0.0.0/0` (모든 IP)

**API 포트 (3002번):**
- Nginx를 통해서만 접근하므로 보안 그룹에 추가 불필요
- localhost만 허용

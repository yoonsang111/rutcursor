## 🚀 파일 업로드 방법

### 방법 1: 직접 복사 (간단)

**서버 터미널에서:**

1. **파일을 직접 만들기**
   - 각 파일을 하나씩 만들기
   - 또는 로컬에서 복사

2. **또는 Git 사용**
   - Git 저장소가 있다면 클론

### 방법 2: SCP 사용 (로컬에서)

**로컬 터미널에서 실행:**

```bash
# 키 파일이 있다면
scp -i ~/.ssh/tour-pem-key.pem -r packages/server/* ubuntu@13.209.15.252:/var/www/api/
```

**하지만 키 파일이 없어서 이 방법은 어려울 수 있습니다.**

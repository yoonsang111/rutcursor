# 보안 그룹 편집 방법 - 상세 가이드

## 🔍 보안 그룹 화면에서 찾아야 할 것

### 화면 구조 확인

보안 그룹 화면에는 여러 버튼이 있을 수 있습니다:

**상단에 있을 수 있는 버튼들:**
- "인바운드 규칙 편집" (Edit inbound rules)
- "규칙 편집" (Edit rules)
- "편집" (Edit)
- 또는 아이콘 버튼 (연필 아이콘 ✏️)

**인바운드 규칙 테이블에서:**
- 각 규칙 옆에 "편집" 버튼
- 또는 테이블 상단에 "규칙 추가" 버튼

---

## 📋 단계별 확인

### 1단계: 보안 그룹 화면 확인

**현재 화면에 무엇이 보이나요?**

다음 중 어떤 것이 보이나요?
- [ ] "인바운드 규칙" 탭
- [ ] 규칙 목록 (테이블)
- [ ] "규칙 추가" 버튼
- [ ] "편집" 버튼
- [ ] 다른 버튼들

### 2단계: 버튼 위치 확인

**상단 오른쪽에 있을 수 있는 버튼:**
- "인바운드 규칙 편집" (주황색 또는 파란색)
- "규칙 편집"
- "편집"

**인바운드 규칙 테이블 상단:**
- "규칙 추가" 버튼
- "편집" 버튼

---

## 🎯 더 간단한 방법: Session Manager 사용

**보안 그룹 수정이 복잡하면:**

### Session Manager로 접속하기

1. **EC2 콘솔로 돌아가기**
   - 왼쪽 상단의 "EC2" 클릭
   - 또는 브레드크럼에서 "인스턴스" 클릭

2. **인스턴스 선택**
   - `tour_stream` 인스턴스 선택

3. **"연결" 버튼 클릭**

4. **"SSM Session Manager" 탭 선택**
   - "EC2 인스턴스 연결" 옆에 있는 탭

5. **"연결" 버튼 클릭**

**이 방법은 보안 그룹 수정이 필요 없습니다!**

---

## 📸 화면 확인

**보안 그룹 화면을 스크린샷으로 보여주시면:**
- 정확한 버튼 위치를 알려드릴 수 있습니다
- 또는 화면에 보이는 버튼들을 설명해주세요

**또는:**
- "상단에 [버튼 이름]이 보여요"
- "인바운드 규칙 테이블이 보여요"
- "규칙 목록만 보여요"

---

## 🚀 추천: Session Manager 먼저 시도

**가장 간단한 방법:**

1. **EC2 콘솔 → 인스턴스**
2. **`tour_stream` 선택**
3. **"연결" 버튼**
4. **"SSM Session Manager" 탭**
5. **"연결" 클릭**

**이 방법이 작동하면 보안 그룹 수정이 필요 없습니다!**

---

## 🆘 도움이 필요하면

**다음 중 하나를 알려주세요:**

1. **Session Manager 탭을 시도했는지**
   - "시도했어요" 또는 "아직 안 했어요"

2. **보안 그룹 화면 설명**
   - 화면에 보이는 버튼이나 텍스트

3. **스크린샷 공유**
   - 보안 그룹 화면 스크린샷

어떤 방법으로 진행할지 알려주세요!

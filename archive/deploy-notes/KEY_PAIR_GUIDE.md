# 키 페어 선택 가이드

## 🤔 현재 상황

EC2 인스턴스를 시작하려고 하시는데 키 페어 선택 대화상자가 나타났습니다.

**중요:** 기존 인스턴스(`tour_stream`)를 시작하는 것인지, 새 인스턴스를 만드는 것인지 확인이 필요합니다.

---

## 📋 두 가지 경우

### 경우 1: 기존 인스턴스 시작 (권장)

**기존 인스턴스 `tour_stream`을 시작하는 경우:**
- 키 페어는 이미 설정되어 있어야 합니다
- "인스턴스 시작" 버튼만 누르면 됩니다
- 키 페어 선택 대화상자가 나오면 "취소"하고 다른 방법 사용

**올바른 방법:**
1. EC2 콘솔 → 인스턴스 목록
2. `tour_stream` 인스턴스 선택
3. 상단의 "인스턴스 시작" 버튼 클릭
4. 키 페어 선택 없이 바로 시작

### 경우 2: 새 인스턴스 생성

**새 인스턴스를 만드는 경우:**
- 키 페어가 필요합니다
- SSH 접속을 위해 필수입니다

---

## 🔑 키 페어란?

**키 페어는 무엇인가요?**
- 서버에 안전하게 접속하기 위한 열쇠입니다
- 공개 키(서버에 저장) + 개인 키(내 컴퓨터에 저장)

**왜 필요한가요?**
- 비밀번호 대신 키로 접속합니다
- 더 안전합니다

---

## ✅ 해결 방법

### 방법 1: 기존 키 페어 사용 (키 페어가 있다면)

1. 드롭다운에서 기존 키 페어 선택
2. 키 페어 이름 확인 (예: `my-key-pair`)
3. "인스턴스 시작" 클릭

**⚠️ 주의:**
- 키 페어 파일(.pem)이 컴퓨터에 있어야 합니다
- 없으면 접속할 수 없습니다

### 방법 2: 새 키 페어 생성 (키 페어가 없다면)

1. "새 키 페어 생성" 선택
2. 키 페어 이름 입력 (예: `tourstream-key`)
3. 키 페어 타입: `RSA` 선택
4. 개인 키 파일 형식: `.pem` 선택
5. "키 페어 생성" 클릭
6. **중요:** 키 파일이 자동으로 다운로드됩니다
7. 다운로드된 파일을 안전한 곳에 보관하세요!

**다운로드 위치:**
- Mac: `~/Downloads/` 폴더
- 파일명: `tourstream-key.pem` (또는 입력한 이름)

### 방법 3: 키 페어 없이 진행 (비권장)

1. "키 페어 없이 계속 진행" 선택
2. "인스턴스 시작" 클릭

**⚠️ 주의:**
- 나중에 SSH 접속이 어려울 수 있습니다
- 다른 방법으로 접속해야 할 수 있습니다

---

## 🎯 추천 방법

### 기존 인스턴스 `tour_stream`을 시작하는 경우

**가장 간단한 방법:**
1. 현재 대화상자에서 **"취소"** 클릭
2. EC2 콘솔로 돌아가기
3. 인스턴스 목록에서 `tour_stream` 선택
4. 상단의 "인스턴스 시작" 버튼 클릭
5. 키 페어 선택 없이 바로 시작

### 새 인스턴스를 만드는 경우

**키 페어 생성 권장:**
1. "새 키 페어 생성" 선택
2. 이름 입력: `tourstream-api-key`
3. 키 페어 생성
4. 다운로드된 파일 보관
5. "인스턴스 시작" 클릭

## 💡 팁

**키 페어 파일이 있으면:**
- 파일 위치 확인: `~/Downloads/` 또는 `~/.ssh/`
- 파일명 확인: `.pem` 확장자

**키 페어 파일이 없으면:**
- 새로 생성하는 것이 좋습니다
- 다운로드된 파일을 꼭 보관하세요!

# 퍼블릭 IP 주소 확인 방법

## 📍 AWS 콘솔에서 확인

### 방법 1: EC2 인스턴스 목록에서 확인

1. **AWS 콘솔 접속**
   - https://console.aws.amazon.com/ec2/
   - 리전: **서울 (ap-northeast-2)** 확인

2. **EC2 서비스 클릭**
   - 검색창에 "EC2" 입력하거나
   - 서비스 목록에서 "EC2" 클릭

3. **인스턴스 목록 확인**
   - 왼쪽 메뉴에서 **"인스턴스"** 클릭
   - 또는 상단 메뉴에서 **"인스턴스"** 클릭

4. **인스턴스 선택**
   - 방금 만든 인스턴스 선택 (체크박스)
   - 인스턴스 이름: `tour-stream-api` 또는 비슷한 이름

5. **퍼블릭 IP 확인**
   - 아래쪽 세부 정보 패널에서 확인
   - 또는 테이블의 "퍼블릭 IPv4 주소" 열에서 확인
   - 예: `13.209.15.252` 같은 숫자

---

### 방법 2: 인스턴스 상세 페이지에서 확인

1. **인스턴스 클릭**
   - 인스턴스 목록에서 인스턴스 이름 클릭

2. **네트워크 탭 확인**
   - 아래 세부 정보에서 **"네트워크"** 섹션 확인
   - **"퍼블릭 IPv4 주소"** 항목 확인

---

## 📸 화면에서 보이는 위치

**인스턴스 목록 테이블:**
- 열 제목: "퍼블릭 IPv4 주소"
- 해당 열의 값이 퍼블릭 IP입니다

**또는 인스턴스 선택 시:**
- 아래 세부 정보 패널
- "네트워크" 섹션
- "퍼블릭 IPv4 주소" 항목

---

## ⚠️ 주의사항

### 퍼블릭 IP가 보이지 않는 경우

1. **인스턴스가 아직 시작 중일 수 있음**
   - 상태가 "실행 중"이 될 때까지 대기 (1-2분)

2. **퍼블릭 IP 자동 할당이 비활성화됨**
   - 인스턴스 설정에서 확인 필요

3. **인스턴스를 다시 시작**
   - 중지 → 시작하면 새 IP 할당

---

## 💡 빠른 확인 방법

**인스턴스 목록에서:**
- 인스턴스 이름 옆에 바로 표시될 수 있음
- 또는 테이블의 "퍼블릭 IPv4 주소" 열 확인

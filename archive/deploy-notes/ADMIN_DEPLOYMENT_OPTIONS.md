# 어드민 배포 옵션

## 🤔 어드민 URL이 필요한가?

어드민은 **내부 관리용**이므로 공개 URL이 필수는 아닙니다. 다음 옵션 중 선택할 수 있습니다:

---

## 옵션 1: 공개 URL 없이 IP 기반 접근 (보안 강화)

### 장점
- ✅ 외부에서 접근 불가 (보안 강화)
- ✅ 비용 절감 (CloudFront 불필요)
- ✅ 간단한 배포

### 단점
- ❌ 외부에서 접근 불가 (집/카페 등에서 작업 불가)
- ❌ VPN 필요

### 구현 방법
1. EC2에 직접 배포 (Nginx로 서빙)
2. 보안 그룹에서 특정 IP만 허용
3. 또는 VPN 연결 필수

### 비용
- EC2 인스턴스만 사용 (기존 API 서버와 공유 가능)
- **추가 비용: 거의 없음**

---

## 옵션 2: 서브도메인으로 공개 (권장)

### 장점
- ✅ 어디서든 접근 가능
- ✅ 메인과 분리된 관리
- ✅ SSL 인증서로 보안 강화
- ✅ CloudFront CDN 활용

### 단점
- ❌ 공개 URL (인증 필요)
- ❌ 약간의 추가 비용

### 구현 방법
1. `admin.tourstream.kr` 서브도메인 생성
2. S3 + CloudFront로 배포
3. 인증 시스템 추가 (선택사항)

### 비용
- S3: 거의 무료 (용량 적음)
- CloudFront: 월 $1-2
- **총: 월 $1-2**

---

## 옵션 3: 메인과 같은 도메인, 다른 경로

### 장점
- ✅ 추가 도메인 불필요
- ✅ 비용 절감

### 단점
- ❌ 메인과 같은 S3 버킷 사용 (복잡)
- ❌ 라우팅 설정 복잡

### 구현 방법
- `tourstream.kr/admin` 경로로 접근
- React Router로 처리

### 비용
- **추가 비용: 없음**

---

## 🎯 추천: 옵션 2 (서브도메인)

### 이유
1. **유연성**: 어디서든 접근 가능
2. **보안**: 인증 시스템 추가 가능
3. **비용**: 월 $1-2로 저렴
4. **관리**: 메인과 완전 분리

### 보안 강화 방법
1. **기본 인증 (Basic Auth)**
   - CloudFront에서 설정
   - 사용자명/비밀번호 입력

2. **IP 화이트리스트**
   - CloudFront에서 특정 IP만 허용
   - 또는 WAF 규칙 사용

3. **인증 시스템 추가** (향후)
   - 로그인 페이지 구현
   - JWT 토큰 기반 인증

## 📝 결정 가이드

**IP 기반 접근을 선택하는 경우:**

- VPN 사용 가능
- 보안 최우선

- 편의성 우선

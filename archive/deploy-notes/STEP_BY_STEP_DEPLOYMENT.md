# 단계별 배포 가이드 - 실전편

## ✅ 확인된 사항
- ✅ tourstream.kr 접속 가능 (메인 앱 배포됨)
- ✅ AWS 계정 있음
- ✅ AWS 콘솔 로그인 가능

---

## 📋 1단계: 현재 상태 확인하기

### 1.1 AWS 콘솔에서 확인할 것들

**AWS 콘솔에 로그인 후 다음을 확인해주세요:**

#### A. S3 버킷 확인
1. AWS 콘솔 → S3 서비스
2. 버킷 목록 확인
3. **질문**: `tourstream` 또는 비슷한 이름의 버킷이 있나요?
   - 버킷 이름: `_________________`

#### B. CloudFront 배포 확인
1. AWS 콘솔 → CloudFront 서비스
2. 배포 목록 확인
3. **질문**: `tourstream.kr` 관련 배포가 있나요?
   - 배포 ID: `_________________`
   - 도메인 이름: `_________________`

#### C. EC2 인스턴스 확인
1. AWS 콘솔 → EC2 서비스
2. 인스턴스 목록 확인
3. **질문**: 실행 중인 인스턴스가 있나요?
   - [ ] 있음 (몇 개: _____)
   - [ ] 없음

#### D. Route 53 확인 (도메인 관리)
1. AWS 콘솔 → Route 53 서비스
2. 호스팅 영역 확인
3. **질문**: `tourstream.kr` 호스팅 영역이 있나요?
   - [ ] 있음
   - [ ] 없음 (다른 곳에서 관리)

---

## 🎯 2단계: 배포 계획

### 배포 순서 (중요!)

```
1️⃣ API 서버 먼저 배포
   ↓
2️⃣ 어드민 앱 배포
   ↓
3️⃣ 메인 앱 업데이트 (환경 변수만)
```

**왜 이 순서인가요?**
- API 서버가 없으면 메인/어드민이 작동하지 않음
- API 서버가 준비된 후 테스트 가능

---

## 🚀 3단계: API 서버 배포 준비

### 3.1 EC2 인스턴스 만들기 (없다면)

**필요한 것:**
- 인스턴스 타입: t3.micro (무료 티어) 또는 t3.small
- OS: Ubuntu 22.04 LTS
- 보안 그룹: HTTP(80), HTTPS(443), SSH(22)

**만드는 방법:**
1. EC2 콘솔 → 인스턴스 시작
2. 단계별로 안내받을 수 있습니다

### 3.2 API 서버 코드 준비

**현재 상태:**
- ✅ 코드 준비됨: `packages/server/`
- ✅ 환경 변수 설정 방법 준비됨
- ✅ PM2 설정 예제 준비됨

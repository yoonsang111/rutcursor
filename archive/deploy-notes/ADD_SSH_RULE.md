# SSH 규칙 추가하기

## 🔍 현재 상태 확인

**보안 그룹:** `sg-0c1fc6eb0acd7607d - default`

**현재 인바운드 규칙:**
- 1개 규칙만 있음
- Type: `All traffic`
- Source: 자기 자신의 보안 그룹 (`sg-0c1fc6eb0acd7607d...`)

**문제:**
- 이 규칙은 같은 보안 그룹 내에서만 통신 가능
- 외부에서 SSH 접속 불가능
- **SSH 규칙을 추가해야 합니다!**

---

## ✅ 해결 방법: SSH 규칙 추가

### 단계별 가이드

#### 1단계: 편집 버튼 클릭

**화면에서 보이는 버튼:**
- **"Edit Inbound Rules"** 버튼 (파란색 버튼)
- 인바운드 규칙 섹션 상단에 있음

**클릭하세요!**

#### 2단계: 규칙 추가

**편집 화면에서:**

1. **"Add rule" 또는 "규칙 추가" 버튼 클릭**

2. **다음 정보 입력:**

   **Type (유형):**
   - 드롭다운에서 `SSH` 선택
   - 또는 `Custom TCP` 선택

   **Protocol (프로토콜):**
   - `TCP` (자동 선택됨)

   **Port Range (포트 범위):**
   - `22` (자동 입력됨)

   **Source (소스):**
   - 옵션 1: **"My IP" (내 IP)** 선택 (권장)
     - 현재 사용 중인 IP만 허용
     - 더 안전함
   - 옵션 2: **"Custom" (사용자 지정)** 선택
     - `0.0.0.0/0` 입력
     - 모든 IP에서 접속 가능 (보안 위험)

   **Description (설명):**
   - `SSH 접속용` (선택사항)

3. **"Save rules" 또는 "규칙 저장" 클릭**

---

## 📋 추가 후 확인

**규칙이 추가되면:**
- 인바운드 규칙 목록에 SSH 규칙이 보임
- Type: `SSH`
- Port: `22`
- Source: `내 IP` 또는 `0.0.0.0/0`

---

## ⚠️ 주의사항

### Source 선택 가이드

**"My IP" (내 IP) 선택 (권장):**
- ✅ 현재 사용 중인 IP만 허용
- ✅ 더 안전함
- ⚠️ IP가 바뀌면 다시 수정 필요 (카페 등 다른 곳에서 접속 시)

**"Custom" → "0.0.0.0/0" (모든 IP):**
- ✅ 어디서든 접속 가능
- ❌ 보안 위험 (모든 IP에서 접속 가능)
- ⚠️ 프로덕션 환경에서는 권장하지 않음

**초기 설정은 "My IP"를 권장합니다!**

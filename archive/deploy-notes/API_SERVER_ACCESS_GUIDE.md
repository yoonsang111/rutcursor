# API 서버 접속 가이드

## ⚠️ 현재 상황

**`https://43.201.66.181/` 접속이 안 되는 이유:**

1. **API 서버는 포트 3002에서 실행 중**
   - 서버 내부에서만 접근 가능 (`localhost:3002`)
   - 외부에서 직접 접근하려면 포트 번호 필요

2. **Nginx 프록시 설정이 안 되어 있음**
   - HTTP (80) / HTTPS (443) 포트로 접속하려면
   - Nginx가 API 서버로 프록시 설정 필요

---

## 🔍 현재 접속 방법

### 방법 1: 포트 직접 접근 (가능)

**외부에서 접속:**
```
http://43.201.66.181:3002/
```

**주의:**
- 보안 그룹에서 포트 3002가 열려있어야 함
- HTTP만 가능 (HTTPS는 인증서 필요)

---

### 방법 2: 서버 내부에서 테스트

**서버 터미널에서:**
```bash
curl http://localhost:3002/
```

**이건 작동해야 합니다!**

---

## ✅ 해결 방법: Nginx 프록시 설정

### 외부에서 `http://43.201.66.181/`로 접속하려면

**Nginx 설정이 필요합니다:**

1. **Nginx 설정 파일 생성**
2. **포트 80 → 포트 3002로 프록시**
3. **보안 그룹에서 포트 80 열기**

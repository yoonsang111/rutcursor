## 📋 다음 확인 사항

### EC2 인스턴스 확인 방법

1. AWS 콘솔 로그인
2. 검색창에 "EC2" 입력
3. EC2 서비스 클릭
4. 왼쪽 메뉴에서 **"인스턴스"** 클릭
5. 인스턴스 목록 확인

**확인할 것:**
- 실행 중인 인스턴스가 있나요?
- 있다면 몇 개인가요?
- 없다면 "없음"이라고 알려주세요

### Route 53 확인 방법

1. AWS 콘솔 로그인
2. 검색창에 "Route 53" 입력
3. Route 53 서비스 클릭
4. 왼쪽 메뉴에서 **"호스팅 영역"** 클릭
5. `tourstream.kr` 호스팅 영역 확인

**확인할 것:**
- `tourstream.kr` 호스팅 영역이 있나요?
- 있다면 레코드 목록 확인
- 없다면 "없음"이라고 알려주세요

# 새 키 페어 생성 옵션

## ⚠️ 중요한 사실

**기존 EC2 인스턴스 (`tour_stream`)는:**
- 이미 `tour-pem-key`로 생성되었습니다
- 새 키 페어를 만들어도 **기존 인스턴스에는 적용할 수 없습니다**
- 기존 인스턴스에 접속하려면 **원래 키 파일**이 필요합니다

---

## 🎯 해결 방법 3가지

### 방법 1: EC2 Instance Connect 사용 (추천! ✅)

**키 페어 파일이 없어도 접속 가능합니다!**

1. AWS 콘솔 → EC2 → 인스턴스
2. `tour_stream` 선택
3. "연결" → "EC2 Instance Connect" → "연결"
4. 브라우저 터미널에서 바로 작업 가능

**장점:**
- 키 파일 불필요
- 가장 간단함
- 바로 시작 가능

---

### 방법 2: 기존 키 파일 찾기

**키 파일이 어딘가에 있을 가능성이 높습니다:**

```bash
# 모든 .pem 파일 찾기
find ~ -name "*.pem" -type f 2>/dev/null

# 일반적인 위치 확인
ls -la ~/Downloads/*.pem
ls -la ~/Desktop/*.pem
ls -la ~/.ssh/*.pem
```

**찾았다면:**
- 경로를 알려주세요
- 제가 SSH 접속해서 설정하겠습니다

---

### 방법 3: 새 키 페어 생성 + 새 인스턴스 (비추천 ❌)

**주의:** 이 방법은 기존 인스턴스의 모든 설정을 잃게 됩니다!

1. 새 키 페어 생성
2. 기존 인스턴스 중지/종료
3. 새 인스턴스 생성 (새 키 페어 사용)
4. 모든 설정을 다시 해야 함

**단점:**
- 기존 설정 모두 손실
- 시간 낭비
- 비용 발생 (새 인스턴스)

---

## 💡 추천 방법

**가장 쉬운 방법: EC2 Instance Connect 사용**

1. 키 파일 찾기 시도
2. 못 찾으면 → EC2 Instance Connect 사용
3. 브라우저 터미널에서 `COMPLETE_API_SETUP.sh` 실행

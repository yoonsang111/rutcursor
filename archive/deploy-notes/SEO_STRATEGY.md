# TourStream SEO 전략

## 📊 현재 SEO 상태 분석

### ✅ 잘 구현된 부분
1. **기본 메타 태그**: title, description, keywords
2. **Open Graph 태그**: 소셜 미디어 공유 최적화
3. **구조화된 데이터 (Schema.org)**: Organization, WebSite, Product, FAQPage
4. **robots.txt**: 검색 엔진 크롤링 허용
5. **sitemap.xml**: 사이트맵 존재 (단, 동적 생성 필요)
6. **동적 메타 태그**: 상품 상세 페이지에서 동적 생성
7. **Google Analytics & Tag Manager**: 분석 도구 연동

### ⚠️ 개선이 필요한 부분
1. **sitemap.xml**: 정적 파일로만 존재, 동적 생성 필요
2. **robots.txt**: 더 세밀한 설정 필요
3. **페이지별 메타 태그**: 카테고리/지역 페이지 SEO 부족
4. **이미지 최적화**: alt 태그, 이미지 크기 최적화
5. **내부 링크 구조**: 사이트 내부 링크 최적화
6. **페이지 속도**: Core Web Vitals 최적화
7. **모바일 최적화**: 반응형은 있으나 추가 최적화 필요

## 🎯 SEO 목표

### 단기 목표 (1-3개월)
1. **검색 엔진 색인**: 모든 상품 페이지 색인
2. **키워드 순위**: 주요 키워드 상위 50위 진입
3. **트래픽**: 월 1,000명 이상 유기적 방문자

### 중기 목표 (3-6개월)
1. **키워드 순위**: 주요 키워드 상위 20위 진입
2. **트래픽**: 월 5,000명 이상 유기적 방문자
3. **전환율**: 검색 유입의 5% 이상 예약 클릭

### 장기 목표 (6-12개월)
1. **키워드 순위**: 주요 키워드 상위 10위 진입
2. **트래픽**: 월 20,000명 이상 유기적 방문자
3. **브랜드 인지도**: "투어 비교" 관련 검색에서 1위

## 🔑 타겟 키워드 전략

### 1. 핵심 키워드 (High Priority)
- **투어 비교** (검색량: 높음, 경쟁: 중간)
- **액티비티 예약** (검색량: 높음, 경쟁: 높음)
- **제주도 패러세일링** (검색량: 중간, 경쟁: 중간)
- **부산 서핑** (검색량: 중간, 경쟁: 낮음)
- **강원도 스키** (검색량: 중간, 경쟁: 중간)

### 2. 롱테일 키워드 (Medium Priority)
- **제주도 패러세일링 가격 비교**
- **부산 서핑 체험 예약**
- **강원도 스키 리조트 할인**
- **제주도 액티비티 추천**
- **전국 투어 한눈에 비교**

### 3. 지역별 키워드 (Long-tail)
- **[지역명] [액티비티명] 예약**
- **[지역명] [액티비티명] 가격**
- **[지역명] [액티비티명] 추천**
- **[지역명] 투어 비교**

## 📝 콘텐츠 전략

### 1. 상품 페이지 최적화
**현재 상태**: 기본적인 SEO 메타 태그만 있음

**개선 방안**:
- 각 상품 페이지에 고유한 메타 설명
- 상품명에 지역명 포함 (예: "제주도 패러세일링")
- 상세 설명에 키워드 자연스럽게 포함
- 사용자 리뷰/평점 추가 (신뢰도 향상)

### 2. 카테고리 페이지 최적화
**현재 상태**: 카테고리 페이지 SEO 부족

**개선 방안**:
- 카테고리별 전용 메타 태그
- 카테고리 설명 페이지 추가
- 카테고리별 인기 상품 섹션
- 관련 카테고리 내부 링크

### 3. 지역 페이지 최적화
**현재 상태**: 지역 페이지 SEO 부족

**개선 방안**:
- 지역별 전용 메타 태그
- 지역 소개 콘텐츠 추가
- 지역별 인기 액티비티 섹션
- 지역별 날씨/시즌 정보

### 4. 블로그/가이드 콘텐츠
**추가 필요**: SEO를 위한 콘텐츠 마케팅

**제안 콘텐츠**:
- "제주도 패러세일링 완벽 가이드"
- "부산 서핑 초보자를 위한 팁"
- "강원도 스키장 비교 가이드"
- "계절별 추천 액티비티"

## 🔧 기술적 SEO 개선

### 1. 동적 Sitemap 생성
**현재**: 정적 sitemap.xml만 존재

**개선**:
```javascript
// 서버에서 동적으로 생성
GET /sitemap.xml
- 모든 상품 페이지 URL
- 카테고리 페이지 URL
- 지역 페이지 URL
- 최신 업데이트 날짜 포함
```

### 2. robots.txt 개선
**현재**: 기본 설정만 있음

**개선**:
```
User-agent: *
Allow: /
Disallow: /admin/
Disallow: /api/
Disallow: /search?*

# Sitemap
Sitemap: https://tourstream.kr/sitemap.xml
Sitemap: https://tourstream.kr/sitemap-products.xml
Sitemap: https://tourstream.kr/sitemap-categories.xml
```

### 3. 페이지 속도 최적화
- 이미지 최적화 (WebP 포맷, lazy loading)
- 코드 스플리팅
- CDN 사용
- 캐싱 전략

### 4. 모바일 최적화
- 모바일 퍼스트 디자인 (이미 구현됨)
- 터치 최적화
- 모바일 페이지 속도 개선

### 5. 구조화된 데이터 확장
**현재**: Organization, WebSite, Product, FAQPage

**추가 제안**:
- **BreadcrumbList**: 모든 페이지에 추가
- **Review/Rating**: 상품 리뷰가 있으면 추가
- **LocalBusiness**: 지역별 비즈니스 정보
- **ItemList**: 카테고리/지역 페이지의 상품 목록

## 🔗 내부 링크 전략

### 1. 사이트 구조
```
홈 (/)
├── 상품 목록 (/products)
├── 카테고리 (/category/[카테고리])
├── 지역 (/location/[지역])
├── 상품 상세 (/product/[id])
└── 검색 (/search?q=[키워드])
```

### 2. 내부 링크 최적화
- **홈페이지**: 인기 카테고리, 인기 지역 링크
- **상품 카드**: 관련 상품 추천
- **상품 상세**: 같은 카테고리/지역 상품 링크
- **카테고리 페이지**: 하위 카테고리 링크
- **지역 페이지**: 같은 지역 다른 액티비티 링크

### 3. 사이트맵 구조
- 메인 사이트맵: 모든 페이지
- 상품 사이트맵: 상품 페이지만 (빠른 업데이트)
- 카테고리 사이트맵: 카테고리 페이지
- 지역 사이트맵: 지역 페이지

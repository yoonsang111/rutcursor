## 📝 1단계: 현재 상태 파악하기

### 1.1 메인 앱이 어떻게 배포되어 있는지 확인

메인 앱이 이미 배포되어 있다면, 어떻게 배포되어 있는지 확인해야 합니다.

**확인 방법:**
1. AWS 콘솔에 로그인
2. S3 버킷 목록 확인
3. CloudFront 배포 목록 확인

**질문:**
- 메인 앱이 S3 + CloudFront로 배포되어 있나요?
- 아니면 다른 방법으로 배포되어 있나요?

### 1.2 필요한 도구 확인

**필요한 도구:**
1. **AWS 계정** - AWS 서비스를 사용하기 위해 필요
2. **AWS CLI** - 명령줄에서 AWS를 제어하기 위해 필요
3. **SSH 접속 도구** - EC2 서버에 접속하기 위해 필요
4. **도메인 관리 권한** - DNS 설정을 위해 필요

## 🛠️ 2단계: 필요한 도구 설치 및 설정

### 2.1 AWS CLI 설치 확인

터미널에서 확인:
```bash
aws --version
```

**결과:**
- 버전이 나오면 → ✅ 설치됨
- "command not found" → ❌ 설치 필요

**설치 방법 (macOS):**
```bash
brew install awscli
```

### 2.2 AWS CLI 설정

```bash
aws configure
```

**입력할 정보:**
1. **AWS Access Key ID**: AWS 콘솔에서 발급받은 키
2. **AWS Secret Access Key**: AWS 콘솔에서 발급받은 키
3. **Default region**: `ap-northeast-2` (서울 리전)
4. **Default output format**: `json`

**어디서 키를 받나요?**
1. AWS 콘솔 로그인
2. 우측 상단 사용자명 클릭 → "보안 자격 증명"
3. "액세스 키" 섹션 → "액세스 키 만들기"

### 2.3 SSH 키 확인

EC2 서버에 접속하기 위해 SSH 키가 필요합니다.

**확인:**
```bash
ls -la ~/.ssh/
```

**SSH 키가 없으면:**
```bash
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```

## 🏗️ 3단계: 배포 계획 수립

### 3.1 배포 순서

**중요: 순서를 지켜야 합니다!**

1. **API 서버 먼저** (가장 중요)
   - 이유: 메인과 어드민이 API 서버에 연결되기 때문
   
2. **어드민 앱 두 번째**
   - 이유: API 서버가 준비된 후 테스트 가능
   
3. **메인 앱 마지막**
   - 이유: 이미 배포되어 있으므로 환경 변수만 업데이트

### 3.2 필요한 AWS 서비스

1. **EC2** - API 서버를 실행할 서버
2. **S3** - 정적 파일(빌드된 앱) 저장
3. **CloudFront** - CDN (빠른 전송)
4. **Route 53** (또는 도메인 제공업체) - DNS 설정
5. **ACM** - SSL 인증서

## 💰 4단계: 비용 확인

### 4.1 예상 비용

**API 서버 (EC2):**
- t3.micro: 월 $7.5 (약 10,000원)
- t3.small: 월 $15 (약 20,000원)

**어드민 앱 (S3 + CloudFront):**
- S3: 거의 무료
- CloudFront: 월 $1-2 (약 1,500원)

**총 비용:**
- **최소**: 월 약 11,500원
- **권장**: 월 약 21,500원

### 4.2 무료 티어 확인

AWS 신규 가입 시:
- EC2 t2.micro: 1년 무료 (월 750시간)
- S3: 5GB 무료
- CloudFront: 1TB 전송 무료

**질문: AWS 계정이 신규인가요?**
- 신규라면 첫 1년은 거의 무료로 사용 가능합니다!

## 🎓 배포 개념 이해하기

### 왜 이렇게 복잡한가요?

**간단한 웹사이트:**
- HTML 파일만 있으면 → S3에 올리면 끝

**우리 프로젝트:**
- **메인 앱**: React 앱 (브라우저에서 실행)
- **어드민 앱**: React 앱 (브라우저에서 실행)
- **API 서버**: Node.js 서버 (서버에서 실행)

**각각 다른 배포 방법이 필요합니다:**
- React 앱 → 빌드 → S3 + CloudFront
- Node.js 서버 → EC2 서버에 설치 → 실행

### 왜 서브도메인을 사용하나요?

```
tourstream.kr          → 메인 앱
admin.tourstream.kr    → 어드민 앱
api.tourstream.kr       → API 서버
```

**이유:**
- 각각 다른 서비스이므로 분리
- 보안 강화 (어드민은 인증 필요)
- 관리 편의성

# 인스턴스가 없어졌을 때 해결 방법

## 🔍 인스턴스 찾기

### 1단계: 필터 확인

**EC2 콘솔에서:**
1. 왼쪽 메뉴 → "인스턴스" 클릭
2. 상단 필터 확인
   - "상태" 필터: "모든 상태" 선택되어 있는지 확인
   - "리전" 확인: 서울(ap-northeast-2)인지 확인

### 2단계: 다른 리전 확인

**리전이 바뀌었을 수 있습니다:**
- 상단 오른쪽 리전 선택 확인
- "아시아 태평양 (서울)" 선택되어 있는지 확인

### 3단계: 종료된 인스턴스 확인

**인스턴스가 종료되었을 수 있습니다:**
- 필터에서 "종료됨" 상태도 확인
- 종료된 인스턴스 목록 확인

---

## 🔄 인스턴스 재생성 (필요한 경우)

### 인스턴스가 정말 없으면 새로 만들어야 합니다

**새 인스턴스 생성 단계:**

#### 1단계: 인스턴스 시작

1. **EC2 콘솔 → 인스턴스**
2. **"인스턴스 시작" 버튼 클릭**

#### 2단계: 기본 설정

**이름 및 태그:**
- 이름: `tour_stream` (또는 원하는 이름)

**애플리케이션 및 OS 이미지(AMI):**
- **Ubuntu 22.04 LTS** 선택
- 또는 **Amazon Linux 2023** 선택

**인스턴스 유형:**
- **t2.micro** 또는 **t3.micro** 선택 (무료 티어)

#### 3단계: 키 페어 설정

**키 페어 선택:**
- **"기존 키 페어 선택"** 선택
- 드롭다운에서 **`tour-pem-key`** 선택
- 또는 **"새 키 페어 생성"** 선택
  - 이름: `tourstream-api-key`
  - 키 페어 생성 후 다운로드 (중요!)

#### 4단계: 네트워크 설정

**보안 그룹:**
- **"기존 보안 그룹 선택"** 선택
- `default` 보안 그룹 선택
- 또는 **"새 보안 그룹 생성"** 선택
  - SSH 규칙 추가 (포트 22, 내 IP)

#### 5단계: 스토리지

**볼륨 설정:**
- 기본값 유지 (8GB)

#### 6단계: 시작

**"인스턴스 시작" 버튼 클릭**

---

## ⚠️ 중요 사항

### 키 페어 파일 보관

**새 키 페어를 생성했다면:**
- 다운로드된 `.pem` 파일을 안전한 곳에 보관
- `~/.ssh/` 폴더로 이동 권장
- 권한 설정: `chmod 400 ~/.ssh/tourstream-api-key.pem`

### 보안 그룹 설정

**인스턴스 생성 후:**
- 보안 그룹에 SSH 규칙 추가 (위에서 설명한 방법)
- HTTP(80), HTTPS(443) 규칙도 추가 (나중에)

---

## 🔍 인스턴스 상태 확인

**EC2 콘솔에서 확인할 것:**
- [ ] 인스턴스 목록에 `tour_stream`이 있는지
- [ ] 상태가 "실행 중"인지
- [ ] 리전이 서울인지
- [ ] 필터가 올바른지

---

## 🆘 도움이 필요하면

**다음 정보를 알려주세요:**

1. **EC2 콘솔에서 보이는 것:**
   - "인스턴스가 없습니다" 메시지가 보이나요?
   - 다른 인스턴스는 보이나요?
   - 필터가 설정되어 있나요?

2. **리전 확인:**
   - 상단 오른쪽 리전이 무엇인가요?
   - "아시아 태평양 (서울)"인가요?

3. **상태 확인:**
   - 종료된 인스턴스 목록에 있나요?

- 위의 단계대로 진행

## 🔍 EC2 확인하기

### 단계별 안내

1. **AWS 콘솔 접속**
   - https://console.aws.amazon.com

2. **EC2 서비스 찾기**
   - 상단 검색창에 "EC2" 입력
   - "EC2" 서비스 클릭

3. **인스턴스 목록 확인**
   - 왼쪽 메뉴에서 **"인스턴스"** 클릭
   - 또는 **"Instances"** 클릭

4. **확인할 것**
   - 목록에 인스턴스가 있나요?
   - 있다면 상태는 무엇인가요? (실행 중, 중지됨 등)
   - 없다면 빈 목록이 보일 것입니다

**스크린샷 예시:**
- 인스턴스가 있으면: 목록에 행이 보임
- 인스턴스가 없으면: "인스턴스가 없습니다" 또는 빈 목록

## 🌐 Route 53 확인하기

### 단계별 안내

1. **AWS 콘솔 접속**

2. **Route 53 서비스 찾기**
   - 상단 검색창에 "Route 53" 입력
   - "Route 53" 서비스 클릭

3. **호스팅 영역 확인**
   - 왼쪽 메뉴에서 **"호스팅 영역"** 클릭
   - 또는 **"Hosted zones"** 클릭

4. **확인할 것**
   - `tourstream.kr` 호스팅 영역이 있나요?
   - 있다면 클릭해서 레코드 확인

**참고:**
- Route 53에 없어도 괜찮습니다
- 다른 도메인 제공업체(가비아, 후이즈 등)에서 관리할 수도 있습니다
- 도메인 DNS 설정을 할 수 있는 곳이면 됩니다

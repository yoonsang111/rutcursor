# 인스턴스를 찾은 후 다음 단계

## ✅ 현재 상태

- ✅ 인스턴스 찾음
- ⏳ 다음: 상태 확인 및 접속

---

## 📋 확인할 사항

### 1단계: 인스턴스 상태 확인

**EC2 콘솔에서 확인:**

1. **인스턴스 상태:**
   - [ ] "실행 중" (Running) - ✅ 좋음
   - [ ] "시작 중" (Pending) - ⏳ 기다리기
   - [ ] "중지됨" (Stopped) - ⚠️ 시작 필요
   - [ ] "종료됨" (Terminated) - ❌ 새로 생성 필요

2. **퍼블릭 IP:**
   - 퍼블릭 IPv4 주소가 표시되는지 확인
   - 예: `13.209.15.252`

3. **보안 그룹:**
   - 어떤 보안 그룹이 연결되어 있는지 확인

---

## 🚀 다음 단계

### 인스턴스가 "실행 중"이면:

1. **보안 그룹 확인**
   - SSH 규칙이 추가되었는지 확인
   - 없으면 추가 (위에서 설명한 방법)

2. **서버 접속 시도**
   - EC2 콘솔 → 인스턴스 → 연결
   - "EC2 Instance Connect" 탭
   - "연결" 클릭

### 인스턴스가 "중지됨"이면:

1. **인스턴스 시작**
   - 인스턴스 선택
   - "인스턴스 시작" 버튼 클릭
   - 1-2분 대기

### 인스턴스가 "시작 중"이면:

1. **기다리기**
   - 1-2분 후 "실행 중"으로 변경됨
   - 상태 새로고침

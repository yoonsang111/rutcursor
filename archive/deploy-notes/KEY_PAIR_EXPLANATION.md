# 키 페어 사용 설명

## 📋 키 페어가 필요한 경우 vs 불필요한 경우

### ✅ 키 페어가 **불필요한** 경우

**1. 메인 앱 배포 (S3 + CloudFront)**
- 메인 앱은 **S3 버킷**에 빌드 파일을 업로드
- **CloudFront**로 CDN 제공
- **키 페어 불필요** ❌
- AWS CLI 또는 콘솔로 업로드:
  ```bash
  aws s3 sync build/ s3://tourstream-website-1758807132/ --delete
  ```

**2. 어드민 앱 배포 (S3 + CloudFront)**
- 어드민 앱도 **S3 + CloudFront**로 배포
- **키 페어 불필요** ❌

---

### 🔑 키 페어가 **필요한** 경우

**1. EC2 서버 접속 (SSH)**
- EC2 인스턴스에 **SSH로 접속**할 때만 필요
- API 서버 설정, 파일 업로드, 명령어 실행 등
- **키 페어 필요** ✅

**2. EC2 인스턴스 생성 시**
- 새 EC2 인스턴스를 만들 때 키 페어 선택/생성
- 한 번만 다운로드 가능

---

## 🤔 현재 상황

**메인 앱 배포 시:**
- S3 + CloudFront 사용 → **키 페어 없이 배포됨**
- 따라서 키 페어 파일이 없을 수 있습니다

**EC2 인스턴스가 있다면:**
- `tour_stream` 인스턴스가 이미 있다면
- 이전에 키 페어를 생성했을 가능성이 있습니다
- 하지만 파일을 잃어버렸을 수도 있습니다

---

## 🔍 확인 방법

### 1. AWS 콘솔에서 키 페어 확인

**EC2 콘솔 → 키 페어:**
1. AWS 콘솔 → EC2
2. 왼쪽 메뉴 → "네트워크 및 보안" → "키 페어"
3. 키 페어 목록 확인
   - `tour-pem-key` 또는 비슷한 이름이 있는지 확인

**키 페어가 있다면:**
- 로컬 컴퓨터에서 찾아보세요
- 보통 `~/Downloads/` 또는 `~/Desktop/`에 있습니다

**키 페어가 없다면:**
- 새로 생성해야 합니다
- 기존 EC2 인스턴스에 연결할 수 없을 수도 있습니다
- 하지만 EC2 Instance Connect를 사용할 수 있습니다

---

## 💡 해결 방법

### 방법 1: 키 페어 파일 찾기

```bash
# 로컬에서 찾기
find ~ -name "*.pem" -type f 2>/dev/null
ls -la ~/Downloads/*.pem
ls -la ~/Desktop/*.pem
```

### 방법 2: EC2 Instance Connect 사용 (키 페어 불필요!)

**AWS 콘솔에서:**
1. EC2 → 인스턴스 → `tour_stream` 선택
2. "연결" 버튼 클릭
3. "EC2 Instance Connect" 탭 선택
4. "연결" 클릭
5. **브라우저에서 터미널이 열립니다!**

**이 방법의 장점:**
- 키 페어 파일 불필요
- 브라우저에서 바로 접속
- 보안 그룹 설정만 확인하면 됨

### 방법 3: 새 키 페어 생성 (기존 인스턴스에 연결 불가)

**주의:** 기존 EC2 인스턴스는 이미 다른 키 페어로 생성되었을 수 있습니다.

---

## 🎯 추천 방법

**가장 쉬운 방법: EC2 Instance Connect 사용**

1. AWS 콘솔 → EC2 → 인스턴스 → `tour_stream` 선택
2. "연결" → "EC2 Instance Connect" → "연결"
3. 브라우저 터미널에서 `COMPLETE_API_SETUP.sh` 내용 붙여넣기

**이 방법이면 키 페어 파일이 필요 없습니다!**

---

## 📝 요약

| 작업 | 키 페어 필요? |
|------|-------------|
| 메인 앱 배포 (S3) | ❌ 불필요 |
| 어드민 앱 배포 (S3) | ❌ 불필요 |
| EC2 SSH 접속 | ✅ 필요 |
| EC2 Instance Connect | ❌ 불필요 |

**결론:**
- 메인 앱 배포 시 키 페어를 사용하지 않았을 가능성이 높습니다
- API 서버 설정을 위해 EC2 접속이 필요합니다
- **EC2 Instance Connect를 사용하면 키 페어 없이 접속 가능합니다!**

# 빠른 서버 접속 가이드

## 🎯 가장 간단한 방법

### EC2 Instance Connect 사용 (키 파일 불필요!)

**단계:**
1. AWS 콘솔 → EC2 → 인스턴스
2. `tour_stream` 인스턴스 선택
3. 상단의 **"연결"** 버튼 클릭 (주황색 버튼)
4. **"EC2 Instance Connect"** 탭 선택
5. **"연결"** 클릭

**결과:**
- 브라우저에서 터미널이 열립니다
- 서버에 접속됩니다!

---

## ✅ 접속 확인

접속되면 다음과 같은 화면이 보입니다:
```
Welcome to Ubuntu...
ubuntu@ip-172-31-44-114:~$
```

이 화면이 보이면 성공입니다!

---

## 📝 접속 후 할 일

접속이 되면 다음 명령어를 실행하세요:

```bash
# 1. 현재 위치 확인
pwd

# 2. 시스템 정보 확인
uname -a

# 3. Node.js 설치 여부 확인
node --version
```

**결과를 알려주시면 다음 단계를 안내하겠습니다!**

---

## 🆘 접속이 안 되면

**"연결" 버튼이 비활성화되어 있으면:**
- 인스턴스가 완전히 시작될 때까지 기다리기 (1-2분)

**"권한이 없습니다" 오류:**
- IAM 권한 확인 필요
- 다른 방법 시도

**문제가 있으면 알려주세요!**

# 보안 그룹 수정 가이드

## 🔧 SSH 연결을 위한 보안 그룹 설정

### 단계별 가이드

#### 1단계: 보안 그룹 찾기

1. **EC2 콘솔 → 인스턴스**
2. **`tour_stream` 인스턴스 선택**
3. **하단 "보안" 탭 클릭**
4. **보안 그룹 이름 확인**: `sg-021c2479c7157707c (default)`
5. **보안 그룹 이름 클릭** (파란색 링크)

#### 2단계: 인바운드 규칙 확인

1. **"인바운드 규칙" 탭 클릭**
2. **현재 규칙 확인**
   - SSH(22번 포트) 규칙이 있는지 확인

#### 3단계: 규칙 추가 (SSH가 없으면)

1. **"인바운드 규칙 편집" 클릭**
2. **"규칙 추가" 클릭**
3. **다음 정보 입력:**
   - **유형**: `SSH`
   - **프로토콜**: `TCP` (자동 선택됨)
   - **포트 범위**: `22` (자동 입력됨)
   - **소스**: 
     - 옵션 1: `내 IP` (권장 - 더 안전)
     - 옵션 2: `0.0.0.0/0` (모든 IP - 보안 위험)
4. **"규칙 저장" 클릭**

#### 4단계: 다시 연결 시도

1. **EC2 콘솔로 돌아가기**
2. **인스턴스 선택 → 연결**
3. **"EC2 Instance Connect" 탭 선택**
4. **"연결" 버튼 클릭**

---

## ⚠️ 보안 주의사항

### 소스 선택 가이드

**"내 IP" 선택 (권장):**
- ✅ 현재 사용 중인 IP만 허용
- ✅ 더 안전함
- ⚠️ IP가 바뀌면 다시 수정 필요

**"0.0.0.0/0" 선택:**
- ✅ 어디서든 접속 가능
- ❌ 보안 위험 (모든 IP에서 접속 가능)
- ⚠️ 프로덕션 환경에서는 권장하지 않음

---

## 🎯 빠른 해결: Session Manager 사용

**보안 그룹 수정이 복잡하면:**

1. **연결 화면에서**
2. **"SSM Session Manager" 탭 선택**
3. **"연결" 클릭**

**이 방법은 보안 그룹 설정이 필요 없습니다!**

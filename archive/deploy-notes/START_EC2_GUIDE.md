# EC2 인스턴스 시작하기

## 🎯 목표

중지된 EC2 인스턴스를 시작하여 API 서버를 배포할 준비를 합니다.

---

## 📋 단계별 가이드

### 1단계: EC2 인스턴스 선택

1. AWS 콘솔 → EC2 서비스
2. 왼쪽 메뉴 → "인스턴스" 클릭
3. `tour_stream` 인스턴스 체크박스 선택
   - 인스턴스가 파란색으로 선택됩니다

### 2단계: 인스턴스 시작

1. 상단의 **"인스턴스 시작"** 버튼 클릭
   - 주황색 버튼입니다
   - 드롭다운이 있으면 "인스턴스 시작" 선택

2. 확인 대화상자
   - "인스턴스를 시작하시겠습니까?" 같은 메시지
   - **"시작"** 또는 **"예"** 클릭

### 3단계: 시작 대기

1. 인스턴스 상태 확인
   - 상태가 "중지됨" → "시작 중" → "실행 중"으로 변경됩니다
   - 새로고침 버튼(🔄)을 눌러서 상태 확인

2. 시작 완료까지 약 1-2분 소요

### 4단계: 시작 완료 확인

**확인할 것:**
- ✅ 상태: "실행 중" (녹색 원)
- ✅ 퍼블릭 IPv4: IP 주소가 표시됨 (예: `13.125.xxx.xxx`)
- ✅ 퍼블릭 IPv4 DNS: DNS 주소가 표시됨 (예: `ec2-13-125-xxx-xxx.ap-northeast-2.compute.amazonaws.com`)

---

## ⚠️ 주의사항

### 비용
- t2.micro는 무료 티어이지만, 조건이 있습니다
- 월 750시간 무료 (거의 한 달 내내 사용 가능)
- 무료 티어가 끝나면 시간당 약 $0.01 (월 $7.5)

### 보안
- 인스턴스가 시작되면 인터넷에 노출됩니다
- 보안 그룹 설정이 중요합니다 (다음 단계에서 설정)

---

## 📝 시작 후 알려주세요

인스턴스가 시작되면 다음 정보를 알려주세요:

1. **퍼블릭 IPv4**: `_________________`
2. **퍼블릭 IPv4 DNS**: `_________________`
3. **상태**: 실행 중인지 확인

이 정보를 주시면 다음 단계(API 서버 배포)를 진행하겠습니다!

---

## 🆘 문제가 생기면

**인스턴스가 시작되지 않으면:**
- 오류 메시지를 확인해주세요
- 스크린샷을 공유해주시면 도와드리겠습니다

**비용이 걱정되면:**
- t2.micro는 매우 저렴합니다
- 사용하지 않을 때는 중지하면 비용이 발생하지 않습니다

- [ ] 퍼블릭 DNS가 표시되었는지 확인

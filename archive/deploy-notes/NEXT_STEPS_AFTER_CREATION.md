# 인스턴스 생성 후 다음 단계

## ✅ 인스턴스 생성 완료!

이제 다음 정보가 필요합니다:

### 1. 인스턴스 정보 확인

**AWS 콘솔에서 확인:**
- EC2 → 인스턴스 → 새로 만든 인스턴스 선택
- **퍼블릭 IPv4 주소** 확인
- **인스턴스 ID** 확인

### 2. 키 파일 위치 확인

**다운로드된 키 파일:**
- 파일명: `tour-stream-api-key.pem`
- 위치: 보통 `~/Downloads/` 또는 `~/Desktop/`
- 전체 경로 알려주세요

### 3. Elastic IP 할당 (선택사항이지만 권장)

**IP 주소를 고정하려면:**
- EC2 → 탄력적 IP → 탄력적 IP 주소 할당
- 할당된 IP를 인스턴스에 연결

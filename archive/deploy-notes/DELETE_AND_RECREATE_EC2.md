# EC2 인스턴스 삭제 및 재생성 가이드

## 🗑️ 1단계: 기존 인스턴스 삭제

### AWS 콘솔에서 삭제

1. **EC2 콘솔 접속**
   - https://console.aws.amazon.com/ec2/
   - 리전: **서울 (ap-northeast-2)**

2. **인스턴스 선택**
   - 왼쪽 메뉴 → "인스턴스"
   - `tour_stream` 인스턴스 선택 (체크박스)

3. **인스턴스 종료**
   - 상단 "인스턴스 상태" → "인스턴스 종료"
   - 확인 메시지에서 "종료" 클릭
   - ⚠️ **주의**: "삭제"가 아니라 "종료"입니다

4. **완료 대기**
   - 인스턴스 상태가 "종료됨"이 될 때까지 대기 (약 1-2분)

---

## 🆕 2단계: 새 인스턴스 생성

### 2.1 인스턴스 시작

1. **EC2 콘솔 → "인스턴스 시작" 클릭**

2. **이름 및 태그**
   - 이름: `tour-stream-api` (또는 원하는 이름)

3. **애플리케이션 및 OS 이미지 (AMI)**
   - **Ubuntu Server 24.04 LTS** 선택
   - 또는 **Ubuntu Server 22.04 LTS**

4. **인스턴스 유형**
   - **t2.micro** 선택 (프리 티어)

5. **키 페어 (로그인)**
   - **"새 키 페어 생성"** 클릭
   - 이름: `tour-stream-api-key`
   - 키 페어 유형: **RSA**
   - 프라이빗 키 파일 형식: **.pem**
   - **"키 페어 생성"** 클릭
   - ⚠️ **자동으로 다운로드됩니다!** 파일 위치 확인

6. **네트워크 설정**
   - VPC: 기본 VPC 선택
   - 서브넷: 기본 서브넷 선택
   - 퍼블릭 IP 자동 할당: **활성화**
   - 보안 그룹: **"새 보안 그룹 생성"**
     - 이름: `tour-stream-api-sg`
     - 설명: `TourStream API Server Security Group`
   - **인바운드 보안 그룹 규칙 추가:**
     - **SSH (22)**: 소스 → "내 IP"
     - **HTTP (80)**: 소스 → "0.0.0.0/0" (모든 위치)
     - **HTTPS (443)**: 소스 → "0.0.0.0/0" (모든 위치)
     - **커스텀 TCP (3002)**: 소스 → "0.0.0.0/0" (API 서버용)

7. **스토리지 구성**
   - 기본 8GB (gp3) 유지

8. **고급 세부 정보** (선택)
   - IAM 인스턴스 프로필: 필요시 설정

9. **인스턴스 시작**
   - 하단 "인스턴스 시작" 클릭
   - 생성 완료 대기 (약 1-2분)

---

## 🌐 3단계: Elastic IP 할당

### 3.1 Elastic IP 생성

1. **EC2 콘솔 → 왼쪽 메뉴 → "탄력적 IP"**

2. **"탄력적 IP 주소 할당" 클릭**

3. **설정:**
   - 네트워크 경계 그룹: 기본값
   - 퍼블릭 IPv4 주소 풀: Amazon의 IPv4 주소 풀

4. **"할당" 클릭**

5. **Elastic IP를 인스턴스에 연결:**
   - 할당된 Elastic IP 선택
   - "작업" → "탄력적 IP 주소 연결"
   - 인스턴스: 새로 만든 인스턴스 선택
   - 프라이빗 IP 주소: 자동 선택
   - "연결" 클릭

## 🔐 4단계: 키 파일 권한 설정

### 로컬 터미널에서 실행

```bash
# 다운로드된 키 파일 경로 확인
ls -la ~/Downloads/tour-stream-api-key.pem

# 권한 설정
chmod 400 ~/Downloads/tour-stream-api-key.pem

# 확인
ls -la ~/Downloads/tour-stream-api-key.pem
# 결과: -r-------- (400 권한)
```

## 🚀 5단계: SSH 접속 및 API 서버 설정

### 5.1 SSH 접속

```bash
# Elastic IP 또는 퍼블릭 IP로 접속
ssh -i ~/Downloads/tour-stream-api-key.pem ubuntu@[Elastic-IP-주소]

# 또는 퍼블릭 IP
ssh -i ~/Downloads/tour-stream-api-key.pem ubuntu@[퍼블릭-IP-주소]
```

## ⚠️ 주의사항

1. **기존 인스턴스 종료 시**
   - 데이터 손실 가능
   - 하지만 API 서버가 아직 설정되지 않았으므로 문제 없을 가능성 높음

2. **Elastic IP**
   - 인스턴스에 연결하지 않으면 비용 발생
   - 반드시 인스턴스에 연결하세요

3. **보안 그룹**
   - SSH (22)는 "내 IP"로 제한 권장
   - HTTP/HTTPS는 "0.0.0.0/0" (모든 위치)

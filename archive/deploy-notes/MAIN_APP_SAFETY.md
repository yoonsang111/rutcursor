## 🔄 EC2 인스턴스 변경 시 영향

### 메인 앱에 영향 없음 ✅

**이유:**
1. 메인 앱은 S3 + CloudFront로 서비스됨
2. EC2는 API 서버용으로만 사용
3. 완전히 분리된 구조

**EC2를 새로 만들어도:**
- ✅ 메인 앱 계속 작동
- ✅ 도메인 (`tourstream.kr`) 계속 접속 가능
- ✅ S3, CloudFront 영향 없음

---

## ⚠️ 주의할 점

### API 서버 설정 후

**메인 앱이 API 서버를 사용하도록 설정되면:**
- 메인 앱 → API 서버로 요청
- API 서버 IP가 변경되면 환경 변수 업데이트 필요
- 하지만 **메인 앱 자체는 영향 없음**

**현재 상태:**
- 메인 앱은 아직 API 서버를 사용하지 않을 수 있음
- 로컬 API 서버(`localhost:3002`)를 사용 중일 수 있음

## 📋 확인 사항

### 메인 앱 환경 변수 확인

**메인 앱이 어디서 API를 호출하는지 확인:**

```javascript
// packages/main/.env 또는 환경 변수
REACT_APP_API_URL=http://localhost:3002/api
// 또는
REACT_APP_API_URL=https://api.tourstream.kr/api
```

**현재 설정:**
- 로컬 API 사용 중이면 → EC2 변경 영향 없음
- 원격 API 사용 중이면 → API 서버 IP 업데이트 필요

# AWS 콘솔 확인 체크리스트

## 📋 확인할 항목들

### 1. S3 버킷 확인

**위치:** AWS 콘솔 → S3

**확인 사항:**
- [ ] 버킷 목록에서 `tourstream` 관련 버킷 찾기
- [ ] 버킷 이름 기록: `_________________`
- [ ] 버킷에 파일이 있는지 확인 (build 폴더 등)

**스크린샷 예시:**
```
버킷 이름 예시:
- tourstream-main
- tourstream-kr
- tourstream-bucket
```

---

### 2. CloudFront 배포 확인

**위치:** AWS 콘솔 → CloudFront

**확인 사항:**
- [ ] 배포 목록 확인
- [ ] `tourstream.kr` 관련 배포 찾기
- [ ] 배포 ID 기록: `_________________`
- [ ] 도메인 이름 확인: `_________________`

**스크린샷 예시:**
```
배포 정보:
- ID: E1234567890ABC
- 도메인: d1234567890.cloudfront.net
- 상태: 배포됨
```

---

### 3. EC2 인스턴스 확인

**위치:** AWS 콘솔 → EC2 → 인스턴스

**확인 사항:**
- [ ] 실행 중인 인스턴스가 있나요?
- [ ] 있다면 몇 개인가요?
- [ ] 인스턴스 타입은 무엇인가요? (t3.micro, t3.small 등)

**스크린샷 예시:**
```
인스턴스 목록:
- 인스턴스 1: i-1234567890abcdef0 (실행 중, t3.micro)
- 인스턴스 2: i-0987654321fedcba0 (중지됨)
```

---

### 4. Route 53 확인 (도메인 관리)

**위치:** AWS 콘솔 → Route 53 → 호스팅 영역

**확인 사항:**
- [ ] `tourstream.kr` 호스팅 영역이 있나요?
- [ ] 있다면 레코드 목록 확인
- [ ] 없다면 다른 곳에서 관리 중일 수 있음

**스크린샷 예시:**
```
호스팅 영역:
- tourstream.kr
  - 레코드: tourstream.kr → CloudFront
  - 레코드: www.tourstream.kr → CloudFront
```

---

## 📸 스크린샷 찍는 방법

**Mac:**
- `Shift + Command + 4` → 영역 선택
- 또는 `Shift + Command + 3` → 전체 화면

**Windows:**
- `Windows + Shift + S` → 영역 선택
- 또는 `Print Screen` → 전체 화면

---

## ❓ 모르겠다면

**각 항목에서 모르는 것이 있으면:**
1. "모르겠다"고 말씀해주세요
2. 스크린샷을 공유해주세요
3. 또는 해당 서비스 화면을 설명해주세요

**예시:**
- "S3에 버킷이 5개 있는데 어떤 게 맞는지 모르겠어요"
- "CloudFront에 배포가 3개 있는데..."
- "EC2 인스턴스가 없어요"

## ✅ 확인 완료 후

위의 정보를 알려주시면:
1. 현재 상태를 정확히 파악
2. 다음 단계를 구체적으로 안내
3. 필요한 작업만 진행

**예시 답변:**
```
1. S3 버킷: tourstream-main
```

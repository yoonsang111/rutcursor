# SSH 키 파일 찾기 및 등록 가이드

## 🔍 1단계: 키 파일이 이미 있는지 확인

### 로컬에서 키 파일 찾기

**터미널에서 실행:**

```bash
# 일반적인 위치에서 찾기
find ~ -name "*tour*.pem" -o -name "*pem*" 2>/dev/null

# 특정 디렉토리 확인
ls -la ~/Downloads/*.pem 2>/dev/null
ls -la ~/Desktop/*.pem 2>/dev/null
ls -la ~/.ssh/*.pem 2>/dev/null
```

**키 파일을 찾았다면:**
- 파일 경로를 알려주세요
- 제가 SSH 접속해서 설정을 진행하겠습니다

---

## 📥 2단계: 키 파일이 없다면 - AWS에서 다운로드

### 방법 A: 기존 키 페어가 있는 경우 (다운로드)

**AWS EC2 콘솔에서:**

1. **EC2 콘솔 접속**
   - https://console.aws.amazon.com/ec2/
   - 리전: **서울 (ap-northeast-2)** 선택

2. **왼쪽 메뉴에서 "키 페어" 클릭**
   - 또는 검색창에 "키 페어" 입력

3. **`tour-pem-key` 찾기**
   - 키 페어 목록에서 `tour-pem-key` 확인
   - **⚠️ 중요**: 키 페어는 한 번만 다운로드 가능합니다
   - 이미 다운로드했다면 다시 다운로드할 수 없습니다

4. **키 페어가 있다면:**
   - 로컬 컴퓨터에서 찾아보세요
   - 보통 `~/Downloads/` 또는 `~/Desktop/`에 있습니다

---

### 방법 B: 키 페어가 없다면 - 새로 생성

**AWS EC2 콘솔에서:**

1. **EC2 콘솔 → 키 페어 → "키 페어 생성" 클릭**

2. **키 페어 설정:**
   - **이름**: `tour-pem-key` (또는 원하는 이름)
   - **키 페어 유형**: RSA
   - **프라이빗 키 파일 형식**: `.pem`

3. **"키 페어 생성" 클릭**
   - 자동으로 다운로드됩니다
   - **⚠️ 중요**: 이 파일을 안전한 곳에 보관하세요!

4. **다운로드된 파일 위치 확인:**
   - 보통 `~/Downloads/tour-pem-key.pem` 또는 `~/Desktop/tour-pem-key.pem`

---

## 🔐 3단계: 키 파일 권한 설정

**터미널에서 실행:**

```bash
# 키 파일 경로를 찾은 후
chmod 400 ~/Downloads/tour-pem-key.pem

# 또는 실제 경로로
chmod 400 [키파일경로]
```

**권한 확인:**
```bash
ls -la ~/Downloads/tour-pem-key.pem
# 결과: -r-------- (400 권한이어야 함)
```

---

## 🚀 4단계: SSH 접속 테스트

**터미널에서 실행:**

```bash
# 키 파일 경로와 서버 IP로 접속 테스트
ssh -i ~/Downloads/tour-pem-key.pem ubuntu@13.209.15.252
```

**성공하면:**
- 서버 터미널이 열립니다
- `ubuntu@ip-xxx-xxx-xxx-xxx:~$` 프롬프트가 보입니다

# 새 EC2 인스턴스 생성 가이드

## 🎯 목표

API 서버를 위한 새 EC2 인스턴스를 생성합니다.

---

## 📋 단계별 가이드

### 1단계: 인스턴스 시작

1. **EC2 콘솔 → 인스턴스**
2. **"인스턴스 시작" 버튼 클릭** (주황색 큰 버튼)

---

### 2단계: 이름 설정

**이름 및 태그:**
- **이름**: `tour_stream` 입력

---

### 3단계: AMI 선택

**애플리케이션 및 OS 이미지(AMI):**
- **Ubuntu 22.04 LTS** 선택 (권장)
- 또는 **Amazon Linux 2023** 선택

**참고:** Ubuntu가 더 일반적이고 문서가 많습니다.

---

### 4단계: 인스턴스 유형

**인스턴스 유형:**
- **t2.micro** 또는 **t3.micro** 선택
- 무료 티어 가능
- "무료 티어 사용 가능" 표시 확인

---

### 5단계: 키 페어

**키 페어 선택:**
- **"기존 키 페어 선택"** 선택
- 드롭다운에서 **`tour-pem-key`** 선택

**또는 새로 생성:**
- **"새 키 페어 생성"** 선택
- 이름: `tourstream-api-key`
- 키 페어 타입: `RSA`
- 개인 키 파일 형식: `.pem`
- **"키 페어 생성" 클릭**
- **중요:** 다운로드된 파일 보관!

---

### 6단계: 네트워크 설정

**네트워크 설정:**
- VPC: 기본값 유지
- 서브넷: 기본값 유지

**보안 그룹:**
- **"기존 보안 그룹 선택"** 선택
- `default` 보안 그룹 선택

**또는 새 보안 그룹 생성:**
- **"새 보안 그룹 생성"** 선택
- 보안 그룹 이름: `tourstream-api-sg`
- 설명: `API 서버용 보안 그룹`
- **인바운드 규칙 추가:**
  - 규칙 1: SSH (포트 22) - 소스: "내 IP"
  - 규칙 2: HTTP (포트 80) - 소스: "0.0.0.0/0"
  - 규칙 3: HTTPS (포트 443) - 소스: "0.0.0.0/0"

---

### 7단계: 스토리지

**구성 스토리지:**
- 볼륨 크기: `8 GB` (기본값)
- 볼륨 유형: `gp3` (기본값)

---

### 8단계: 요약 및 시작

**요약 확인:**
- 설정이 올바른지 확인
- 무료 티어 사용 가능 확인

**"인스턴스 시작" 버튼 클릭**

---

## ✅ 생성 후 확인

**인스턴스가 생성되면:**
- 인스턴스 목록에 나타남
- 상태: "시작 중" → "실행 중"
- 퍼블릭 IP 할당됨

**확인할 정보:**
- 인스턴스 ID: `_________________`
- 퍼블릭 IPv4: `_________________`
- 상태: `_________________`

---

## 🔧 보안 그룹 설정

**인스턴스 생성 후 보안 그룹 수정:**

1. 인스턴스 선택 → 보안 탭
2. 보안 그룹 클릭
3. 인바운드 규칙 편집
4. SSH 규칙 추가 (위에서 설명한 방법)

---

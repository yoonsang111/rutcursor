# 서버 접속하기 - 버튼 클릭

## 🎯 지금 할 일

### 하단의 "연결" 버튼 클릭!

**위치:**
- 화면 하단 오른쪽
- 주황색 버튼
- "연결" 또는 "Connect"라고 적혀있음

**설정 확인:**
- ✅ 연결 유형: "퍼블릭 IP를 사용하여 연결" 선택됨
- ✅ 퍼블릭 IPv4 주소: `13.209.15.252` 표시됨
- ✅ 사용자 이름: `ubuntu` (기본값, 올바름)

**모든 설정이 올바르게 되어 있습니다!**

---

## 📋 클릭하면

**"연결" 버튼을 클릭하면:**
- 새 브라우저 탭이 열립니다
- 서버에 접속됩니다
- 터미널 화면이 나타납니다

---

## ✅ 접속 확인

접속되면 다음과 같은 화면이 보입니다:

```
Welcome to Ubuntu 22.04.3 LTS (GNU/Linux ...)
...
ubuntu@ip-172-31-44-114:~$
```

**이 화면이 보이면 성공입니다!** ✅

---

## 🚀 다음 단계

접속이 되면:

1. **접속 확인**
   - 터미널 프롬프트가 보이는지 확인
   - `ubuntu@ip-...:~$` 같은 화면

2. **기본 명령어 테스트**
   ```bash
   pwd
   ls
   ```

3. **알려주세요**
   - "접속되었어요!" 또는
   - "이 화면이 보여요: [화면 설명]"

---

## 🆘 문제가 있으면

**"연결할 수 없습니다" 오류:**
- 보안 그룹의 SSH 규칙 Source 확인
- 현재 IP와 일치하는지 확인

**화면이 안 열리면:**
- 팝업 차단 확인
- 새 탭에서 열리도록 설정

**다른 오류:**
- 오류 메시지를 알려주세요

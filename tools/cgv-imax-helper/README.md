# 용아맥 2인 좌석 선점 도우미

개인 관람용 스크립트입니다. 오픈을 감시하다가 열리면 **중앙 우선 순위**에 따라 2연석을 선점하고, **결제는 직접** 합니다.

## 좌석 순위 기준

```
점수 = 0.7 × (중앙 벗어남)^1.5 + 0.3 × (J~K열에서 벗어난 줄 수 / 전체 줄 수)
```

- 선호 열은 J~K입니다. 이 범위 안은 행 감점이 없습니다.
- 동점이면 뒷줄을 먼저 고릅니다.
- 중앙은 좌석 번호가 아니라 배치도에 그려진 실제 x 좌표로 계산합니다.
- 통로를 사이에 둔 자리, 판매된 자리, 장애인석, 커플석은 제외합니다.
- 값은 `seat_rank.py` 맨 위에서 바꿀 수 있습니다.

`python seat_rank.py`를 실행하면 가상 배치 기준 순위를 미리 볼 수 있습니다.

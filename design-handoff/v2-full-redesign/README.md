# V2 Full Redesign Handoff

이 폴더에 피그마에서 추출한 코드/이미지/에셋을 그대로 넣어주세요.

## 폴더 용도
- `pages/`: 페이지 단위 시안/코드
- `components/`: 공통 컴포넌트 코드
- `assets/`: 이미지, 아이콘, 폰트

## 최소로 알려주면 좋은 정보
1. 어떤 파일이 어떤 경로인지
   - 예: `pages/home.tsx -> /v2`
   - 예: `pages/products.tsx -> /v2/products`
   - 예: `pages/product-detail.tsx -> /v2/product/:id`
2. 우선 구현 순서
   - 예: products -> detail -> home

정보를 모르더라도 우선 파일만 넣어주시면, 제가 구조를 먼저 분석해서 진행하겠습니다.
